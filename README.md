## UI Automation Testing — Playwright + Java + Allure

Проект автоматизации UI-тестирования на Java с использованием Playwright, JUnit 5 и Allure Report.
CI настроен через GitHub Actions, а отчёты автоматически публикуются в GitHub Pages.

### Реализованные проверки
 - Поиск товаров
 - Переход по категориям
 - Рота с корзиной (добавление / удаление)
 - Пверка пустой корзины
 - Синшоты при ошибках
